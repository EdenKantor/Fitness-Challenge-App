# 🏋️‍♂️ WebFitPro – Fitness Challenge App

**WebFitPro** is a full-stack fitness application that enables users to participate in challenges, track their progress, and share feedback with the community.  
Built with a responsive and intuitive interface, the platform promotes motivation, personal goal-setting, and social engagement for fitness enthusiasts.

### 🌐 Live Demo  
🔗 [https://web-fit-pro-front-kappa.vercel.app](https://web-fit-pro-front-kappa.vercel.app)

---

## 🧩 Tech Stack

| Layer      | Technology                          |
|------------|--------------------------------------|
| Frontend   | Preact, Tailwind CSS                 |
| Backend    | Node.js, Express.js, MongoDB         |
| Deployment | Vercel (Frontend), Vercel (Backend) |

---

## ✨ Features

- 👤 **User authentication** and session persistence
- 🧱 **Admin dashboard** for user approvals and moderation
- 📈 **Progress tracking** for completed fitness challenges
- 🎨 **Light/Dark mode toggle** with preference memory
- 🧠 **BMI calculator** and motivational quotes
- 🧭 **Challenge filtering** by body zone and difficulty
- 💬 **Community sharing** – users can recommend and comment on challenges
